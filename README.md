# MacBook Second-Hand Inspector

Open-source macOS toolkit for evaluating used MacBooks before purchase.

## Features
- Hardware and model information
- Battery cycle count and health
- Security and MDM checks (not conclusive)
- Fullscreen display pixel inspection
- Keyboard key testing

## How to use
Download the repository ZIP, open `EKRAN_TESTI.html` and `KLAVYE_TESTI.html` in a browser, and run `CALISTIR.command` on macOS for a system report.

> These tests cannot certify genuine replacement parts, absence of hidden MDM enrollment, or freedom from physical defects. Always erase and reactivate the Mac with the seller before payment.

## Privacy
Review generated reports before sharing. Do not publish device serial numbers.
